MODEL SPECIFICATION

Computation and assumptions

01

Checkpoint and projections

Tokenizer and BF16 weights from Qwen3-0.6B ↗. Token vector (1024) → input RMSNorm → learned Wq / Wk → Q/K RMSNorm. Select any of the 16 Q heads in layer 0; Q head h uses KV head floor(h / 2). Shared mode explicitly replaces K with Q before rotation, as an experimental control.

02

Rotary convention

128 dimensions form 64 split-half pairs (xᵢ, xᵢ₊₆₄), matching Qwen. θᵢ = b−2i/128, with b = 1,000,000 by default. The base controls angular frequencies; it is independent of softmax scaling. Query rotates by mθᵢ; key rotates by nθᵢ.

03

YaRN transformation

A linear ramp preserves high frequencies and divides low frequencies by s. Attention correction a = 1 + c ln(s), with c = 0.1 by default, scales both vectors. Logits are multiplied by λ = a²; manual mode sets λ directly. The attention comparison uses identical frequencies in both columns.

04

Runtime and deeper layers

Calculations run directly in browser JavaScript, without Hugging Face Transformers. Before the first attention operation, Q/K are independent of surrounding tokens. Deeper layers require a full contextual forward pass. The attention panel normalizes over the entered key tokens only; it excludes Q's own K and any unspecified intervening tokens. It does not compute V or a model continuation.

⟨R(m)q, R(n)k⟩ = ∑ᵢ |qᵢ| |kᵢ| cos(αᵢ − βᵢ + (m − n)θᵢ)

Positions are zero-indexed with m ≥ n. Selected tokens are placed at the specified positions; intervening text is not generated. Float64 calculations from BF16 weights may differ slightly from BF16 inference. YaRN paper ↗ · Model config ↗
